## 🛠️ Technology Stack

- **Framework:** React 19 + TypeScript + Vite
- **Routing:** React Router DOM
- **Styling:** Tailwind CSS v4 with custom luxury theme tokens
- **Forms & Validation:** React Hook Form + Zod
- **Icons:** Lucide React
- **SEO & Schema:** DaySpa JSON-LD Structured Data, OpenGraph, Twitter Cards, robots.txt, sitemap.xml
- **Resilience:** `FallbackImage` component with Zero-Broken-Image Policy

## 🚀 Setup & Development Instructions

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation
```bash
# Clone the repository and install dependencies
npm install
```

### Running Locally
```bash
npm run dev
```
Open your browser at `http://localhost:3000` (or the port specified by Vite).

### Production Build
```bash
npm run build
```
Generates optimized, production-ready static assets in the `dist` directory.

### Preview Production Build
```bash
npm run preview
```
